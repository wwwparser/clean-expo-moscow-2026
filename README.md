# CleanExpo Moscow 2026 — навигатор выставки

Русскоязычный статический портал по открытым источникам организатора и участников. В нём собраны 117 участников, 418 позиций продукции, 40 событий деловой программы, 113 спикеров и 305 публикаций из 31 подтверждённого Telegram-канала организатора и участников. В срезе найдено пять уникальных объявлений о подарках, конкурсах или розыгрышах, прямо связанных с CleanExpo Moscow 2026. Это датированный срез, а не обновляемый API и не полная история Telegram.

Публичная версия портала: https://wwwparser.github.io/clean-expo-moscow-2026/.

## Локальная сборка

Нужен Python 3.10 или новее.

```powershell
python -m http.server 8000 --directory docs
```

Откройте http://localhost:8000.

## Основные разделы

- Участники: 117 официальных карточек, фильтр и поиск, стенды, описания, сайты и email из карточек организатора.
- Продукция: 418 строк из всех 18 страниц официального каталога; связь с участником добавлена только при совпадении ID.
- Программа: 40 мероприятий, даты и время из встроенных данных официальной страницы; одно несоответствие даты отмечено источником.
- Спикеры: 113 карточек, связанные с событиями программы.
- Telegram: до десяти последних сообщений организатора и каналов участников, чьи ссылки найдены на официальных сайтах компаний и страницах контактов; поиск, выдержки и оригиналы. Это ограниченный снимок публичных превью, а не полная история каналов и не полный охват социальных сетей.
- Анализ публикаций: все 305 записей обработаны по схеме розыгрыш/конкурс/подарок/скидка/прочее и проверены на цитаты и выставочную принадлежность. 28 записей без читаемого текста не позволяют установить условия. У пяти объявлений, связанных с Москвой 2026, показываются известные условия и отдельно обозначенные пробелы.
- Предложения: отдельный список уникальных механик из публикаций, с датами, условиями и статусом проверки; повторы одного кода не дублируют предложение.
- Схема: переход на интерактивный план организатора. Геометрия стендов порталом не выдумывается.

## Сборка и источники

`data/portal/*.json` — входные данные сборщика. Для повторной загрузки карточек участников используйте `python scripts/collect_cleanexpo.py`; промежуточный кэш лежит в `data/raw/cleanexpo/`. Каталог продукции загружается `python scripts/collect_products.py`. `python scripts/discover_telegram_channels.py` ищет публичные ссылки на Telegram на сайтах участников; для дополнительных страниц контактов использовался навык `contact-scraper`. Скрипт `python scripts/assemble_official_data.py` собирает производные каталоги и Telegram-ленту; `python scripts/analysis_queue.py --project . prepare` готовит новые посты к проверяемой разметке. После анализа выполняются `python scripts/build_giveaways.py`, `python scripts/build_portal.py` и `python scripts/check_portal.py docs`. Скрипты не вступают в каналы и не отправляют сообщения.

В Git намеренно не входят полные тексты Telegram и локальный архив превью. Папка `docs/` содержит готовую опубликованную сборку; для повторной генерации ленты восстановите локальный снимок в `data/portal/posts.json` и протокол анализа. Если снимка нет, генератор остановится с понятной ошибкой вместо публикации пустой ленты.

Полный текст публикаций и протоколы разбора остаются локальными и исключены из Git. В публичную сборку входят только короткие выдержки и ссылки на оригинал. Ключи API не нужны; `.env` не публикуется.

Раздел `section_map.json` хранит проверенные официальные URLs и границы покрытия. Для списка компаний и товаров указываются реальные карточки источника; неизвестные рубрики, характеристики и даты не дополняются догадками.

## Файлы

```text
expo.json                         настройки портала
section_map.json                  карта официальных источников
data/portal/                      входные данные сборки
scripts/collect_cleanexpo.py      сбор карточек участников
scripts/assemble_official_data.py сбор программы, спикеров, продукции и Telegram
scripts/analysis_queue.py        проверяемая очередь анализа публикаций
scripts/build_giveaways.py       сбор уникальных событий из проверенного разбора
scripts/build_portal.py           генератор статического сайта
scripts/check_portal.py           проверка структуры и ссылок сборки
portal_web/                       шаблоны, стили и клиентский поиск
docs/                             опубликованный статический сайт
artifacts/                        браузерные проверки, скриншоты и аудит
```

Источники данных — [официальный сайт CleanExpo Moscow](https://www.cleanexpo-moscow.ru/ru-RU/), официальные сайты компаний и публичные превью Telegram-каналов, ссылки на которые опубликованы этими сайтами. Даты проверки показаны в соответствующих разделах. Полные тексты Telegram не публикуются; сайт показывает краткие выдержки с переходом к оригиналу.
