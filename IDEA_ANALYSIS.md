# Разбор идеи и результат

## Цель и аудитория

Статический русскоязычный портал помогает посетителям CleanExpo Moscow 2026 находить участников, стенды, продукцию и события деловой программы. Основная аудитория выведена из назначения каталога: посетители, закупщики клининговых компаний и представители экспонентов.

## Выбранный вариант

Python, Jinja2 и JSON формируют автономный статический сайт. Данные собираются адаптерами, сайт публикуется на GitHub Pages. Постоянный API и серверная база для ежегодного события не нужны. Стек: Python 3.10+, Jinja2, BeautifulSoup, HTML/CSS/JavaScript и GitHub Pages.

## Состав данных

- 117 карточек участников с официального интерактивного плана; есть подтверждённые стенды, залы, павильон, описание, логотипы и контакты из карточек организатора.
- 418 товаров из всех 18 страниц официального каталога. Связь с участником указана только там, где совпадают идентификаторы источника.
- 40 мероприятий и 113 спикеров из официальных публичных данных программы. Одно расхождение дат сохранено как предупреждение источника.
- 305 последних публикаций из 31 публичного Telegram-канала: канал организатора и 30 каналов/пользовательских страниц, на которые участники ссылаются с официальных сайтов. Полные тексты остаются локально; в публичном HTML — короткая выдержка и ссылка на оригинал.
- Все 305 публикаций прошли классификацию по категориям и проверку доказательств и выставочной принадлежности. Собрано 16 уникальных предложений/событий, из них пять объявлений прямо связаны с CleanExpo Moscow 2026. У 28 сообщений не было читаемого текста.
- Схема ведёт на официальный интерактивный план. Геометрия и расположение стендов не выдумываются.

## Источники и ограничения

Список участников по официальному плану содержит 117 строк; публикация организатора называет 120 компаний. Объяснение расхождения в источниках не найдено, поэтому каталог следует плану и показывает оба числа.

Ссылки на Telegram проверялись на официальных сайтах и доступных страницах контактов. Сайты указаны в 114 карточках; 23 запроса завершились ошибкой доступа и не трактуются как отсутствие канала. Доступное Telegram-превью ограничено последними сообщениями, не включает приватную историю и иногда не раскрывает вложения.

## Публикация и приёмка

Публичный адрес: https://wwwparser.github.io/clean-expo-moscow-2026/.

Проверка сборки подтверждает 238 HTML-страниц и целостность внутренних ссылок и ассетов. Интерфейс просмотрен при 1440×1000 и 390×844; проверены поиск участника A601, продукции AQUALON, профиль участника, клавиатурная навигация, переключение темы и консоль браузера. Отчёты и скриншоты сохранены в `artifacts/`.
